# Personal site — adaptive long memory for volatility forecasting

**https://adarka-bon.github.io/**

The personal site of the master's research *"Transformer architectures with an adaptive
long-memory mechanism for forecasting financial time-series volatility and assessing market
risk"* (Department of Probability Theory and Mathematical Statistics, Faculty of Applied
Mathematics and Informatics, Belarusian State University).

Interactive demos:

* **Methods** — long memory in volatility, GPH / R/S estimators, and attention-head maps with a
  memory-strength slider;
* **Results** — a seven-model comparison across four metrics (RMSE, MAE, R², directional
  accuracy) with switchable series;
* **Market risk** — an interactive VaR / ES calculator for normal and heavy-tailed laws;
* **Practical value** — four application scenarios and a reproduction workflow.

Source code, data and results: <https://github.com/Adarka-Bon/memory-adaptive-volatility>
